# Waiting-room number announcements

Pre-recorded English clips for the outdoor TV and Live Queue Control.

- Files: `number-1.wav` … `number-99.wav`
- Phrase: “Number twelve”
- Voice: macOS **Karen** (clear PA tone — not Samantha / browser TTS)

Regenerate (macOS only):

```bash
php scripts/generate-announce-audio.php
```
