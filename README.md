# Doctor App - SaaS Platform

A multi-tenant SaaS platform for private doctor chambers and diagnostic clinics in Bangladesh.

## Phases

* **Phase 0: Foundation** (Laravel setup, Tenancy, Isolation tests, Super Admin panel)
* **Phase 1: Booking engine** (Scheduling model, Booking pipeline, Queue status)
* **Phase 2: Staff dashboard** (Daily roster, Walk-in entry, Schedule management)
* **Phase 3: Website & PWA** (Section library, Tenant authoring, /book route, Custom code, PWA)
* **Phase 4: Diagnostics & payments** (Lab tests, Payment webhooks, WhatsApp links, Translations)
